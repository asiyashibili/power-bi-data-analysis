# Sales Performance Dashboard | Power BI

## Project Overview
This project analyzes Microsoft's Financial Sample dataset using Power BI to explore sales and profitability performance across products, countries, segments, and time periods. An interactive dashboard was developed to summarize key performance indicators (KPIs) and present business insights through data visualization.

## Objectives
- Analyze overall sales and profitability performance.
- Identify trends in monthly sales.
- Compare sales performance across countries and products.
- Explore performance across different business segments.
- Present key metrics through an interactive dashboard.

## Dataset
**Financial Sample Dataset**

The dataset contains financial and sales information used to analyze performance across products, countries, business segments, and time periods.

## Tools Used
- Microsoft Power BI
- Data visualization
- Interactive dashboard design

## Dashboard Features
- **2 KPI cards** displaying key performance metrics.
- **3 charts** for exploring sales and profitability.
- **Year slicer** to filter the dashboard by year.
- **Segment slicer** to explore performance across business segments.
- Interactive visualizations for exploring the dataset.

## Key Performance Indicators
- **Total Sales:** 118.73M
- **Total Profit:** 16.89M
- **Profit Margin:** Approximately 14.22% (calculated as Total Profit divided by Total Sales)

## Key Insights
- **Monthly Sales:** October recorded the highest monthly sales peak in the analysis.
- **Country Performance:** The United States recorded the highest sales among the countries displayed.
- **Product Profitability:** Paseo was the most profitable product in the analysis.
- **Overall Profitability:** Total profit was approximately 14.22% of total sales, based on the reported totals.

This project demonstrates the use of Power BI to summarize business performance, compare sales and profitability across categories, and present key findings through an interactive dashboard.
